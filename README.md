# 🧙‍♂️ The Magic Coder

> 🚀 A full-stack blog application built with Python and Flask, designed to share programming knowledge, learning experiences, projects, and useful tips.

---

## ✨ Features

- 🔐 Admin authentication and session management
- 📊 Admin dashboard for managing blog posts
- ✍️ Create, edit, and delete blog posts
- 📝 Markdown support for blog content
- 🖼️ Image upload and image replacement
- 🔎 Blog post search
- 📄 Pagination for blog posts
- 📩 Contact form with database storage
- 📧 Email notifications for contact messages
- 🗑️ Contact message management
- 🛡️ CSRF protection for forms
- 🚫 Custom 404 error page
- ⚙️ Environment-based configuration
- 🗄️ MySQL database integration
- 🔧 Git/GitHub version control
